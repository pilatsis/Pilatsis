## 🗂️ Projects:

🧪 **Thesis — LLM Pen-Test Agent** &nbsp;`[private]`  
An autonomous penetration testing agent powered by a large language model. Given a target web application, the agent independently plans attack strategies, selects and executes exploits from a custom multi-stage attack library, and generates structured vulnerability reports. Built with Python and Docker, combining LLM reasoning with real offensive security techniques including XSS, SQL injection, IDOR, CSRF, and command injection.

🏀 **Euroleague Predictor** &nbsp;`[private]`  
A machine learning pipeline built with XGBoost to predict game statistics and match outcomes for Euroleague basketball. Trained on historical match data with feature engineering across team performance metrics, home/away splits, and rolling averages. Outputs both win probability and key stat projections for upcoming fixtures.
